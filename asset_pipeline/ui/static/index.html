Asset Pipeline

New project

Create or pick a project to start.

Site and shots (world mode)

One city instead of separate scenes. site/layout.json (districts, rings, radial avenues, plots, kits, shots) builds a Blender greybox; after that the .blend is the source of truth: move buildings or cameras in Blender, then Re-read .blend. Each shot camera renders depth, canny and object-id passes that guide its concept frames. Blender runs on the CPU (seconds per shot).

Concept frames per shot (world mode)

Each shot's frames are drawn onto its greybox passes (depth + edges), with the project's style anchor and a prompt built from what the camera sees and the districts' notes. Star the frames that set the look; starred frames can be added to other shots as references, to carry materials across. About 40 s per frame (ComfyUI, GPU 1). Match is how much of the greybox's layout a frame keeps (1 = all of its edges, 0 = no better than chance).

1 · Explore scenes

Generate environment concepts from a brief. Star the scenes worth keeping. Starred scenes go to scene analysis (stage 1) and are the source for the style anchor below.

2 · Derive anchor objects

Pick a starred scene and name objects in it. Each one is cut out with SAM 3 and redrawn as a whole object on white in the scene's style. Star the good ones (cutouts or redraws).

Moodboard

Reference images for the style (e.g. a PureRef board: export its images to a folder, then upload them here, one group at a time). Moodboard images can be used in Derive objects like scenes, and the vision LLM can draft the style text from them (GPU 0).

3 · Style anchor

The starred derived objects plus this style text condition every later image. The text carries most of the style; the images add the look.

Start low (0.06). If new images pick up parts of the anchor objects (awnings, produce…), lower it or star more varied objects; if the style is too weak, raise it a little or strengthen the style text.

1 · Scenes

Starred scenes from stage 0, plus any you upload. Pick one and analyse it: the vision LLM lists the assets to model, with counts, real-world sizes and where they sit. When ComfyUI is running, SAM 3.1 then redraws the boxes (solid); dashed boxes are the LLM's own.

2 · Asset plan

Relations

    Reference sheets

    Each included asset of every plan, drawn on white in the project's style: three views side by side, a kit's pieces together in one sheet, ground surfaces as a top-down texture. Star the sheets worth keeping; stage 3 cuts the views out of starred sheets. About 55 s per sheet (ComfyUI, GPU 1).

    Views and 3D

    Starred reference sheets are cut into separate views (SAM 3.1). For each asset, click the view to build it from, tag it (game, cine or hero), then Make 3D: TRELLIS.2 on GPU 0, about 2.5 min. Hero assets will get a multi-view path later; for now they go through TRELLIS too.
