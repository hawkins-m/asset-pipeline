Stages

    Site / City: City = procedural layout, Site = your own Blender layout; use one or the other.

    Jobs

    Create or pick a project to start (File › New project).

    Explore scenes

    Generate environment concepts from a brief. Starred scenes go to scene analysis and are the source for the style anchor.

    Derive anchor objects

    Pick a starred scene and name objects in it. Each is cut out with SAM 3 and redrawn on white in the scene's style. Star the good ones.

    Moodboard

    Reference images for the style, one group at a time. They can be used in Derive objects like scenes, and the vision LLM can draft the style text from them (GPU 0).

    Style anchor
    0.06

    Start low (0.06). If new images pick up parts of the anchor objects, lower it; if the style is too weak, raise it a little or strengthen the text.

    Site and greybox

    site/layout.json builds a Blender greybox; after that the .blend is the source of truth: move buildings or cameras in Blender, then Re-read .blend. Blender runs on the CPU.

    Aerial previews

    This project has no city layout yet.

    Each shot camera renders depth, edges and object-id passes that guide its frames.

    World mode: the assets the locked shot frames show, from their object-id passes. Each card crops the best current shot frame (the asset bright, the rest dimmed); flags come from SAM 3.1 (trees, sky, something else over the asset). Decide each one before the pilot sheets: Frame crop (the crop guides its sheets), Description only (built from its description), Description + chosen image (its description plus a frame you pick) or Exclude. Pressing a chosen button again clears it.

    Scenes

    Starred scenes from Style, plus any you upload. The vision LLM lists the assets to model with counts, sizes and placement; SAM 3.1 then redraws the boxes (solid; dashed are the LLM's own).

    Asset plan

    Relations

      Each included asset drawn on white in the project's style: three views side by side, a kit's pieces in one sheet, ground as a top-down texture. Star the sheets to keep. About 55 s per sheet.

      Views and 3D

      Reference views are extracted from starred sheets (SAM 3.1). Per asset, pick the view to build from, tag it game, cine or hero, then Make 3D (TRELLIS.2 on GPU 0, about 2.5 min).

      Steps
      1. 1Create UE project An empty project in the Unreal projects folder, with the plugins the import needs.
      2. 2Export The greybox as stand-in GLBs plus the UE manifest, in export/ (Blender, CPU).
      3. 3Import The manifest into the UE level, headless (a wholesale relayout is Import with Reset layout and Prune, after a backup).
      4. 4Render shots Each shot camera rendered in Unreal, offscreen on a GPU with little VRAM in use.
      5. 5Match look A look scene per approved shot: its library builds, light and ground matched to the locked frame.
      Back up the UE project

      Snapshots without its caches; unchanged files are hard-linked, 10 kept.

      Layout

      In the Unreal menu: Pull layout (moves made in Unreal back into the greybox), Stale report….
